# 장국영 · Max Jang

**Java · Kotlin · Spring Boot 기반 백엔드 개발자**

웹·앱 서비스의 API를 개발해 왔습니다. 데이터 모델링과 클라우드 인프라 운영, 배포 자동화도 맡았습니다.
지금은 SK쉴더스에서 시설관리·원격 모니터링 플랫폼의 백엔드를 개발합니다. AKS와 GitLab CI/CD 환경도 운영합니다.

[이력서](https://cv.maxjang.com) · [블로그](https://maxjang.com) · [LinkedIn](https://www.linkedin.com/in/max-jang/) · [이메일](mailto:max@maxjang.com)

## 주요 경험

- **시설관리 플랫폼** — 29개 SKT 사옥의 설비·에너지·보안 데이터를 통합하도록 백엔드 API와 외부 시스템 연동 기능을 개발했습니다.
- **BAS·IoT 데이터 수집** — Apache Milo로 OPC-UA 클라이언트를 만들었습니다. 커넥션 풀, 재연결·재시도와 중복 알람 방지를 구현하고 수집 이벤트는 Azure Event Hubs와 Elasticsearch로 전달했습니다.
- **클라우드 운영·배포 자동화** — AKS Node Pool과 Kubernetes 리소스를 구성하고 운영했습니다. GitLab Runner와 CI/CD 빌드·배포 파이프라인도 구축했습니다.
- **콘텐츠·이커머스 백엔드** — 콘텐츠 수집·검수·배포 시스템과 Kotlin 기반 B2B 이커머스 API를 개발했습니다. 상품·옵션 모델 재설계, SQL·JPA 쿼리 개선과 Redis 캐싱을 담당했습니다.
